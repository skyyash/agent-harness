# Journal

A running log of corrections, annoyances, and discovered preferences.
This file is the fuel for the harness: rules in `instructions/AGENTS.md`
should trace back to entries here, or to something said plainly in a session.
Rules without a traceable reason get deleted.

## Entry format

Append under today's date:

- What happened (one line)
- Rule candidate it suggests (one line)
- Status: new / promoted to instructions / rejected
